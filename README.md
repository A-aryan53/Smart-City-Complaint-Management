# Smart City Complaint Management System

A Java-based Smart City Complaint Management System developed as a micro project.

## Project Overview

The Smart City Complaint Management System is a Java-based software application developed to manage civic complaints through a simple and organized digital platform.

The system consists of two main interfaces:

- Citizen Portal
- Operator Portal

## Features

### Citizen Portal
- Citizen login using Citizen ID
- Register new complaints
- Automatic complaint ID generation
- Automatic department assignment
- Automatic priority assignment
- View complaint history
- Track complaint status

### Operator Portal
- Operator login
- View registered complaints
- Dashboard with complaint statistics
- View complaint details
- Update complaint status
- Manage complaints
- Record work-start and completion information
- View complaint work history

## Complaint Status

The complaint follows the status flow:

Pending → In Progress → Resolved

## Technologies Used

- Java
- Java Swing
- Java AWT
- Java Collections
- Java File Handling
- Java Serialization
- Java Date and Time API

## Data Storage

The application uses local file handling and Java serialization for persistent storage of complaint records.

Database file:

`smartcity_database.dat`
